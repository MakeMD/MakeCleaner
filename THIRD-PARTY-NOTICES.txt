MakeCleaner - third-party notices
==================================

MakeCleaner contains no telemetry, no ads and makes no network connections.
It ships the following third-party components:

1. Winapp2.ini (rules\Winapp2.ini)
   By the Winapp2 project - https://github.com/MoscaDotTo/Winapp2
   License: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
   https://creativecommons.org/licenses/by-sa/4.0/
   Shipped unmodified (Non-CCleaner flavor). The license covers only this data file,
   not the MakeCleaner program. See rules\README.md.

2. Dear ImGui v1.93.0 (docking branch), compiled into MakeCleaner.exe
   https://github.com/ocornut/imgui
   License: MIT (full text below)

3. dear_bindings v0.27 (C API "dcimgui" for Dear ImGui), compiled into MakeCleaner.exe
   https://github.com/dearimgui/dear_bindings
   License: MIT (full text below; it is the license file shipped with the dear_bindings release)

   https://www.sqlite.org
