# 08: Tools — Uninstall і Startup

**What to build:** Uninstall: список встановлених програм (назва, видавець, дата, розмір, версія; HKLM/HKCU, 32/64) з пошуком, запуск деінсталятора / Repair / Change, видалення лише запису з реєстру. Startup: вкладки Windows (Run-ключі, папки автозапуску), Scheduled Tasks, Context Menu, Windows Services — увімкнути / вимкнути / видалити.

**Blocked by:** 01

**Status:** done

- [x] Список програм збігається з «Програми та компоненти» (на машині юзера 212 проти 213: бракує лише «Remote Desktop Connection», яке ARP бере не з Uninstall-реєстру)
- [x] Вимкнення автозапуску оборотне (так само, як це робить Диспетчер задач) — StartupApproved для Run/папок, Shell Extensions\Blocked для контекстного меню, попередній тип старту служби запам'ятовується
- [x] Видалення запису реєстру — з підтвердженням
- [x] Дії, що потребують адміна, просять UAC лише в момент дії (спершу пряма спроба, при access denied — elevated reg/schtasks/sc; на реальних HKLM-записах не прогонялось)

Нотатки: Store-застосунки в Uninstall не показуються; системні служби (образ у %windir%/system32) видаляти заборонено. GUI-смоук: `tools/guismoke-tools.ps1` (лише читання).
