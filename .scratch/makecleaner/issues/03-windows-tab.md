# 03: Вкладка Windows (система, Explorer, Edge)

**What to build:** вкладка Windows з групами Edge, Windows Explorer, System, Advanced. Пункти описані власним набором правил у форматі winapp2 (написаним з документації Windows, не з CCleaner) плюс вбудовані процедури для того, що не виражається правилом: Кошик (опція «лише старше 24 год»), Temp (опція 24 год), буфер обміну, DNS-кеш, кеш ескізів, журнали подій Windows, недійсні ярлики Start Menu / Desktop. Ризиковані пункти Advanced вимкнені за замовчуванням і з попередженням.

**Blocked by:** 02

**Status:** done

- [x] Кожен вбудований пункт має Analyze з розміром/кількістю і Clean
- [x] Кошик і Temp поважають опцію «старше 24 год»
- [x] Пункти Advanced за замовчуванням вимкнені й показують попередження
- [x] Власний набір правил проходить той самий парсер, що й Winapp2.ini

**Notes (done):** правила — `rules/Windows.ini` (вбудований ресурсом), нові ключі `SpecialKey=` і `AgeOption=`. Процедури в `Special.cs`: файлові (Кошик через `$I`/`$R` з часом видалення, биті ярлики через WScript.Shell — лише відсутні цілі на локальних фіксованих дисках) йдуть звичайним шляхом Clean (secure delete, пропуск заблокованих); дії (буфер, DNS, журнали подій через elevated wevtutil) — рядками в результатах, виконуються лише на Clean. Кеш ескізів — звичайне FileKey-правило. Wipe Free Space став правилом в Advanced (не зберігається між запусками). Edge-група поки лише кеш — повний набір браузерних пунктів робить тікет 05. На реальній системі виконувались лише Analyze; Clean для Кошика/буфера/DNS/журналів подій не запускався (тести — фікстури та Analyze).
