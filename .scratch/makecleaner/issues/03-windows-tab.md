# 03: Вкладка Windows (система, Explorer, Edge)

**What to build:** вкладка Windows з групами Edge, Windows Explorer, System, Advanced. Пункти описані власним набором правил у форматі winapp2 (написаним з документації Windows, не з CCleaner) плюс вбудовані процедури для того, що не виражається правилом: Кошик (опція «лише старше 24 год»), Temp (опція 24 год), буфер обміну, DNS-кеш, кеш ескізів, журнали подій Windows, недійсні ярлики Start Menu / Desktop. Ризиковані пункти Advanced вимкнені за замовчуванням і з попередженням.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Кожен вбудований пункт має Analyze з розміром/кількістю і Clean
- [ ] Кошик і Temp поважають опцію «старше 24 год»
- [ ] Пункти Advanced за замовчуванням вимкнені й показують попередження
- [ ] Власний набір правил проходить той самий парсер, що й Winapp2.ini
