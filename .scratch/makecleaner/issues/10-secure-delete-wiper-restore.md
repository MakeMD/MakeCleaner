# 10: Secure delete, Drive Wiper, System Restore

**What to build:** Options: звичайне або безпечне видалення (1/3/7/35 проходів) — застосовується до всіх чисток. Пункт «Wipe Free Space» в Advanced. Drive Wiper: лише вільне місце або весь диск, підтвердження введенням слова, попередження для SSD. System Restore: список точок відновлення, видалення будь-якої, крім останньої.

**Blocked by:** 01

**Status:** done

- [x] Системний диск не можна стерти повністю; повне стирання вимагає введення слова
- [x] Для SSD показується попередження про знос
- [x] Остання точка відновлення не видаляється

**Notes (done):** патерни проходів — у коментарі на початку SecureDelete.cs (1 = нулі, 3 = DoD 5220.22-M, 7 = DoD ECE, 35 = Gutmann). Wipe Free Space пише файли з DeleteOnClose, тож навіть після краху на диску нічого не лишається. Список/видалення точок відновлення і Entire Drive вимагають адміна (UAC лише в момент дії); на живих дисках і реальних точках відновлення не запускалось, тільки UI-смоук (tools/guismoke-tools.ps1). MFT free space і cluster tips свідомо не стираються.
