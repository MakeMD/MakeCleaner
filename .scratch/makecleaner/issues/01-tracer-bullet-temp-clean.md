# 01: Tracer bullet — Analyze і Clean для Temp

**What to build:** користувач запускає MakeCleaner.exe, бачить один пункт «Temporary Files», тисне Analyze — отримує список файлів із загальним розміром, тисне Clean — файли видалено, звіт показує звільнене місце. Під капотом: каркас рішення (.NET 10 WinForms + один тестовий проєкт), мінімальний парсер правила (FileKey + розгортання env-змінних), portable-режим (portable.dat поруч з exe → налаштування в ini поруч, інакше %AppData%), автоматична перевірка, що збірка не посилається на мережеві API.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Analyze нічого не видаляє, показує кількість файлів і розмір
- [x] Clean видаляє лише знайдене Analyze; заблоковані файли пропускаються без падіння й рахуються окремо
- [x] Portable: з portable.dat налаштування пишуться поруч з exe, без нього — в %AppData%\MakeCleaner
- [x] Тест падає, якщо будь-яка збірка MakeCleaner посилається на System.Net.*
- [x] Тест на фікстурі в тимчасовій папці: правило з маскою видаляє лише збіги
