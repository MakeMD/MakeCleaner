# 05: Браузери — Chromium-родина і Firefox

**What to build:** для кожного знайденого браузера (Chrome, Edge, Brave, Vivaldi, Opera / Opera GX, Arc, Firefox — усі профілі) пункти: кеш, історія, історія завантажень, остання папка завантажень, cookies, сесія, дані форм, паролі, compact databases. Одна реалізація на всю Chromium-родину, параметризована шляхом профілю. Якщо браузер запущений — пропозиція закрити його перед чисткою.

**Blocked by:** 02

**Status:** done

- [x] Браузер, якого немає, не показується; кілька профілів обробляються всі
- [x] Паролі, форми, сесія за замовчуванням вимкнені й з попередженням
- [x] Запущений браузер: діалог «закрити / пропустити», без тихого вбивання процесу
- [x] Тест на фікстурі профілю Chromium і Firefox у тимчасовій папці

**Нотатки (done):**
- Окрема вкладка Cleaner → Browsers з власною реалізацією; секції Winapp2 цих 8 браузерів (`Section=... Web Browser`) приховуються в Applications, щоб не було дублів. Решта браузерів (Yandex, Chromium, LibreWolf тощо) лишаються з Winapp2.
- Профілі: Chromium — `Default`, `Profile N`, `Guest Profile` з файлом Preferences (Opera — сам корінь); Firefox — усі `[Profile*]` з profiles.ini, відносні й абсолютні. Кеш Opera/Firefox береться з local-сторони.
- Файлові пункти йдуть через Engine (excludes, secure delete). Не-файлові — через SQLite (`Microsoft.Data.Sqlite`): історія завантажень, форми, compact; історія Firefox — рядки, бо в places.sqlite лежать закладки. Остання папка завантажень — ключ у Preferences (JSON) / рядок у prefs.js.
- Cookies — поки видалення файлу; у пункту стабільний `Id = "cookies"`, тікет 06 підмінить його на видалення рядків.
- Запущений браузер: Так = CloseMainWindow і очікування до 10 с (без kill), Ні = пропустити цей браузер, Скасувати = нічого не чистити. Opera та Opera GX ділять opera.exe, тож закриваються разом.
- Analyze відкриває бази лише read-only. `tools/guismoke.ps1` (клацає Run Cleaner) тепер підміняє LOCALAPPDATA/APPDATA на порожню папку — інакше браузерні пункти, увімкнені за замовчуванням, почистили б справжні браузери. Новий `tools/guismoke-browsers.ps1` — фіктивні Chrome і Firefox, тільки Analyze.
- Не перевірено вживу: діалог закриття на справжньому запущеному браузері й реальний Clean профілів (лише фікстури).
