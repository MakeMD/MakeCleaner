# 05: Браузери — Chromium-родина і Firefox

**What to build:** для кожного знайденого браузера (Chrome, Edge, Brave, Vivaldi, Opera / Opera GX, Arc, Firefox — усі профілі) пункти: кеш, історія, історія завантажень, остання папка завантажень, cookies, сесія, дані форм, паролі, compact databases. Одна реалізація на всю Chromium-родину, параметризована шляхом профілю. Якщо браузер запущений — пропозиція закрити його перед чисткою.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Браузер, якого немає, не показується; кілька профілів обробляються всі
- [ ] Паролі, форми, сесія за замовчуванням вимкнені й з попередженням
- [ ] Запущений браузер: діалог «закрити / пропустити», без тихого вбивання процесу
- [ ] Тест на фікстурі профілю Chromium і Firefox у тимчасовій папці
