# 09: Tools — Duplicate Finder і Disk Analyzer

**What to build:** Duplicate Finder: пошук дублікатів за іменем / розміром / датою / вмістом (хеш лише серед однакових за розміром), ігнор нульових / системних / прихованих / read-only, межі розміру, include/exclude папки, вибір і видалення. Disk Analyzer: розподіл місця за типами (картинки, музика, документи, відео, архіви, пошта, інше) по вибраних дисках, список файлів, відкрити папку, видалити, зберегти звіт у текст.
