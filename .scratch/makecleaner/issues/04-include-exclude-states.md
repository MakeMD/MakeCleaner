# 04: Include/Exclude і збереження станів чекбоксів

**What to build:** в Options користувач додає власні папки/файли на чистку (Include: лише файли / з підпапками / з самою папкою, опція «старше N год») і виключення (Exclude: папка, файл, ключ реєстру). Стан усіх чекбоксів Clean запам'ятовується між запусками. Корінь диска і системні папки відхиляються при додаванні в Include.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Include-пункти з'являються в Advanced і чистяться через той самий рушій
- [ ] Exclude застосовується до всіх джерел (вбудовані, Winapp2, Include)
- [ ] Спроба додати C:\ або %windir% в Include — відмова з поясненням
- [ ] Стани чекбоксів відновлюються після перезапуску (portable і звичайний режим)
